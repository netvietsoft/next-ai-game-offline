# Thư mục chứa khóa xác thực GA4 / GA4 Credentials Directory

Đặt tệp JSON Service Account tải từ Google Cloud Console vào đúng đường dẫn sau:

```text
GA4/credentials/service-account.json
```

> [!CAUTION]
> - **TUYỆT ĐỐI KHÔNG** commit hoặc gửi nội dung `service-account.json` lên Git / chat công khai.
> - Tệp `GA4/credentials/*.json` đã được chặn tự động trong `.gitignore` (trừ `service-account.example.json`).
> - Xem hướng dẫn từng bước tại [HUONG_DAN_LAY_KEY_GA4.md](../HUONG_DAN_LAY_KEY_GA4.md).
